Duplicate Review finds exact or visually similar files across all loaded videos or the current filtered view. It groups the results, suggests one keeper per group, and gives you tools to mark likely copies. It never deletes files automatically.

![Duplicate review](/screenshots/V2.0.0%20-%20DuplicationMode.png)

## Run detection

Duplicate detection needs at least two videos in its configured scope and waits for required metadata work to finish. Start it from the sidebar, or enable **Run after each scan** when duplicate review is the normal purpose of every session.

Choose **All loaded videos** to compare across every session root. Choose **Current filtered view** to limit work to the active grid filters, such as one folder, date range, rating, or status.

Exact-file checks are part of the run. The selected comparison method controls the sampled visual matching used for non-identical files:

| Method | Best use | Tradeoff |
| --- | --- | --- |
| Visual similarity | Alternate encodes, resized copies, and near-identical footage | Broader matching can produce more false positives. |
| pHash | Stricter image-signature comparison | Can miss transformations that visual similarity still recognizes. |

The methods can find different results. Run them separately when coverage matters more than processing time.

## Tune matching

Similarity is the minimum score required to create a match. Raise it when unrelated videos appear together; lower it when known alternate encodes are missed. Visual results below roughly 95 percent deserve especially careful review.

Sample count controls how many points in each video contribute evidence. More samples take longer but reduce the chance that one common frame, intro, or title card creates a false match.

Advanced controls handle harder libraries:

- Sampling windows can avoid repeated intros and outros, including a custom percentage range.
- Duration tolerance limits how different runtimes may be before comparison.
- Requiring every sample is stricter than allowing the average to pass.
- Black- or white-pixel ignoring can reduce the effect of fades, letterboxing, and flashes.
- Flipped comparison checks horizontally mirrored copies.
- Maximum sampling duration limits work on long files; `0` uses the full duration.
- Checkpoint intervals save progress during long runs, and retry can revisit failed fingerprints.

Change one matching control at a time, then run detection again. Existing groups are results from the previous run; changing a setting does not silently rebuild them.

## Read and filter results

Switch between compact rows and thumbnail gallery cards from the duplicate sidebar. Both show group boundaries, exact or potential-match badges, similarity, status, selected keeper, and useful quality metadata.

Duplicate-list filters are independent from the main grid filters. Search duplicate paths or filenames, set a minimum similarity, and sort groups by similarity, group size, or total size. **Reset duplicate filters** returns to all groups sorted by highest similarity.

Play any result to open Review at that video with only its duplicate group as the navigation scope. Returning restores the duplicate-list scroll position.

## Understand keeper suggestions

The selected keeper is a recommendation, not an approval. The automatic ranking compares the configured priority order: resolution, video bitrate, duration, FPS, and file size by default. The first unequal rule wins.

**Protect marked keep videos** removes already-kept files from automatic delete suggestions. **Protect skipped videos** does the same for Skipped files when enabled. Protection affects selection suggestions; it does not make the underlying match more accurate.

Right-click a video and choose **Set as selected keeper** when human context outweighs the automatic ranking. Clear the manual override from the group menu to use automatic ranking again.

## Select and mark copies

<Steps>
  <Step title="Inspect each group">
    Compare thumbnails, similarity, paths, duration, resolution, bitrate, FPS, and size. Play uncertain files before accepting a suggestion.
  </Step>
  <Step title="Select suggested deletions">
    Choose **Select suggested deletions** to select non-keeper videos from the currently visible groups. Review the selected count and individual checks before continuing.
  </Step>
  <Step title="Correct the selection">
    Toggle individual rows or cards, change the selected keeper, or clear the selection. Right-click a group to select suggestions for only that group.
  </Step>
  <Step title="Mark selected as Delete">
    This changes statuses to Delete and leaves files on disk. Return to the grid, filter by Delete, and run the normal confirmed delete action only after the batch is correct.
  </Step>
</Steps>

Status protection and keeper suggestions do not lock a file. Targeted context-menu actions can mark a video Keep, Delete, or Pending when you intentionally need an override.

## Ignore false matches

Use **Not a match** after selecting exactly two videos from the same group. The pair is saved in ignored-match settings and excluded from later duplicate runs. In a two-video group, the current group disappears immediately; in a larger group, rerun detection to rebuild the remaining relationships.

Right-click actions provide broader corrections:

- **Exclude from group** ignores one video against every other video in that group.
- **Dismiss group** ignores every pair in the group and hides it from future runs.
- The toast **Undo** action restores the ignored pairs and current group while the toast remains available.
- **Clear ignored matches** in Settings allows all saved pairs to be considered again on the next run.

Use ignored matches for definite false positives. If many groups are wrong in the same way, tune the matcher and rerun instead of dismissing them one by one.

<Warning>
  Duplicate status marks feed the same global delete batch as grid and Review decisions. The final delete action includes all loaded videos marked Delete, even if current filters hide them.
</Warning>
