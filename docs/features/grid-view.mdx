Grid view is where most large-library triage happens. Every video appears as a card with thumbnail frames sampled from different points in the file, so you can understand what a clip contains without opening it first.

![Grid view](/screenshots/V2.0.0%20-%20GridView.png)

## Filter first

Grid view is where you reduce a large folder into something specific enough to review or batch-edit with confidence.

Use search, status, folder, size, duration, duplicate, rating, favorite, and incompatible filters to get the list down before you enter review mode.

## Sort and group

Sorting changes which clips rise to the top. Grouping changes whether you see one mixed queue or folder buckets with their own local order.

Stay ungrouped when you want one global queue. Turn on folder grouping when keeping folder context matters more than absolute ranking.

## Batch actions

Batch selection is the fast path for marking many rows after filtering has already isolated the right set.

Select after filtering, apply one batch action, then keep moving. Drop back to per-card actions when the remaining set has mixed outcomes or when you need playback before deciding.

## What you can do

- Change card size with `Ctrl++` and `Ctrl+-`.
- Search by filename or path.
- Group by subfolder and see per-folder counts and sizes.
- Filter by status, rating, favorites, compatibility, file size, and duration.
- Sort by name, size, duration, date, rating, resolution, or FPS.
- See badges for codec, resolution, FPS, favorite state, rating, and playback compatibility.

## Batch actions

Use the grid when you already know what a clip is from the thumbnails alone.

- Mark selections as Keep, Delete, Skip, or Reset.
- Clear selection without changing statuses.
- Regenerate thumbnails for selected items.
- Open review mode for a single folder from its sidebar action.

## Folder and session controls

Grid view also handles broader session management:

- Drag and drop folders into the app.
- Work with more than one directory in the same session.
- Reopen recent directories with timestamps.
- Hide the interface with the privacy screen using `Shift+Esc`.

<Tip>
  Start in grid view, then switch to review mode only when the thumbnail strip is not enough to make a decision.
</Tip>
