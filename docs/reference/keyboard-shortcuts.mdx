Video Cull is built around keyboard-first review. The web tables show the defaults. Inside the app, these same marked tables show your currently configured bindings.

## Grid and general

{/* in-app-shortcuts:Global */}
| Shortcut | Action |
| --- | --- |
| `Ctrl + ,` | Open settings |
| `Ctrl + O` | Open directory |
| `Ctrl + F` | Search loaded videos |
| `F5` | Rescan |
| `Ctrl + Z` | Undo |
| `Ctrl + Backspace` | Send marked videos to the Recycle Bin |
| `Ctrl + Shift + R` | Clear cache and reload |
| `Ctrl + Shift + E` | Export an HTML report |
| `Ctrl + E` | Reveal in Explorer |
| `Ctrl + P` | Play externally |
| `Ctrl + +` / `Ctrl + =` / `Ctrl + -` | Zoom cards |
| `F11` | Toggle fullscreen |
| `F1` | Open documentation |
| `Shift + ?` | Open the keyboard shortcuts reference |
| `M` | Toggle global mute |
| `Shift + Esc` | Toggle privacy screen |
{/* /in-app-shortcuts */}

## Review mode

{/* in-app-shortcuts:Review mode */}
| Shortcut | Action |
| --- | --- |
| `K` | Keep |
| `D` | Mark for deletion |
| `S` | Skip |
| `R` | Reset to Pending |
| `Z` | Undo |
| `Space` | Play or pause |
| `Left` / `Right` | Previous or next video, or scrub 5 seconds while playing |
| `Tab` | Next undecided video |
| `Enter` | Play in-app |
| `Ctrl + Enter` | Open in external player |
| `B` | Drop bookmark |
| `[` / `]` | Playback speed down or up |
| `Esc` | Stop or exit review |
{/* /in-app-shortcuts */}

## Preview

{/* in-app-shortcuts:Preview */}
| Shortcut | Action |
| --- | --- |
| `Left` | Rewind 5 seconds |
| `Right` | Forward 5 seconds |
| `Esc` | Close preview |
{/* /in-app-shortcuts */}

## Customization

Review shortcuts are customizable in Settings. If you prefer a different hand layout, remap the decision keys there instead of fighting the defaults.
