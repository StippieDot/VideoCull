VideoCull is built around keyboard-first review. The web tables show the defaults. Inside the app, these same marked tables show your currently configured bindings.

| --- | --- |

| `Ctrl + O` | Open folder |
| `Ctrl + F` | Search loaded videos |
| `F5` | Rescan |

| `Ctrl + Shift + E` | Export an HTML report |

| `Ctrl + +` / `Ctrl + =` / `Ctrl + -` | Larger or smaller cards |

## Menu bar

Every command is also in the menu bar at the top of the window, and **Ctrl + K** (or the search icon in the title bar) finds and runs any of them by name. Hold `Alt` to see each menu's access key, then press it to open the menu: `Alt + F` File, `Alt + A` Actions, `Alt + V` View, `Alt + D` Video, `Alt + H` Help. Commands that cannot do anything right now, such as **Rescan** without an open folder or **Reveal in Explorer** without an open or selected video, are greyed out.

| Menu | Commands |
| --- | --- |
| File | Open Folder, Add Folder to Session, Open Recent, Rescan, Reveal Folder in Explorer, Close Session, Export Report, Settings, Clear Cache and Reload, Exit |
| Actions | Undo, Find Duplicates, Pause Processing, When Processing Finishes, Delete Marked Videos |
| View | Command Palette, Go to Folder, Sort By, Group by Folder, Clear All Filters, Larger and Smaller Cards, Privacy Screen, Mute In-App Playback (when enabled), Dark / Light theme, Full Screen |
| Video | Play Externally, Reveal in Explorer, Copy Path and Regenerate Thumbnails for the video open in Review or the videos selected in the grid; Play Externally and Reveal in Explorer need exactly one video |
| Help | Documentation, Online Help, Keyboard Shortcuts, Release Notes, Report a Problem, Open Log Folder, Check for Updates (direct download only), Support VideoCull (GitHub Sponsors or PayPal), About VideoCull |

The middle of the title bar shows where you are: in the grid, the path of the folder at the top of the screen; in Review, the path of the open video; in duplicate groups, the number of groups. Select any part of the path for a menu with counts and actions for that spot:

- **Grid folder:** Review This Folder, Show Only This Folder, Regenerate Thumbnails, Reveal in Explorer, Copy Path and Go to Folder.
- **Video in Review:** Reveal in Explorer, Play Externally, Copy Path, Review Only This Folder and Show Folder in Grid.
- **Duplicate groups:** Find Duplicates Again, Duplicate Settings and Back to Grid, with the space you could reclaim.

In the grid, each `›` in the path lists the folders one level down, with how many videos each still has to review; pick one to scroll there. Folders with nothing left to review are dimmed. A `›` after the last part appears when that folder has subfolders. With several folders loaded, the arrow at the start of the path switches between them. A path too long for the title bar is shortened to `…` in the middle; select `…` to reach the folders it hides.

**Go to Folder** (`Ctrl + G`) jumps to any folder in the grid: type any part of its path. Before you type, it lists the folders you jumped to recently, then the ones with the most left to review.

In these menus, the arrow keys move through the items, `Left` and `Right` move to the neighbouring part of the path, and `Esc` closes the menu.

While VideoCull is processing, the right side of the title bar shows what it is working on and how far it is, with a pause button, and a progress line runs along the bar's bottom edge.

While the privacy screen is shown, only **Privacy Screen**, **Full Screen** and **Exit** work.

## Customization

Review, Search, theme, global mute, and shortcut-help bindings are customizable in Settings. App and window commands such as opening folders, rescanning, deleting the marked batch, clearing cache, exporting, fullscreen, documentation, and privacy are fixed.

Click a keybind field, press the new combination, and save. `Esc` cancels recording. VideoCull detects conflicts between configurable actions and blocks saving until they are resolved. **Reset defaults** restores all configurable bindings at once.

Review bindings remain active when the embedded player has focus. The app claims configured Review shortcuts before the player's built-in keyboard behavior, so the default `K` performs Keep during playback.

<Tip>
  The in-app shortcut page replaces the default values in these tables with your currently configured bindings.
</Tip>
