title: Keyboard shortcuts
description: Full reference for the default grid, review mode, and general shortcuts in Video Cull.
---

Video Cull is built around keyboard-first review. The defaults below cover the main grid, global actions, and review mode.

## Grid and general

| Shortcut | Action |
| --- | --- |
| `Ctrl + O` | Open directory |
| `Ctrl + F` | Search loaded videos |
| `F5` | Rescan |
| `Ctrl + Z` | Undo |
| `Ctrl + Backspace` | Send marked videos to the Recycle Bin |
| `Ctrl + Shift + R` | Clear thumbnail cache |
| `Ctrl + E` | Reveal in Explorer |
| `Ctrl + +` / `Ctrl + -` | Zoom cards |
| `F11` | Toggle fullscreen |
| `?` | Open the keyboard shortcuts reference |
| `Shift + Esc` | Toggle privacy screen |

## Review mode

| Shortcut | Action |
| --- | --- |
| `K` | Keep |
| `D` | Mark for deletion |
| `S` | Skip |
| `Z` | Undo |
| `Space` | Play or pause |
| `Left` / `Right` | Previous or next video, or scrub 5 seconds while playing |
| `Tab` | Next undecided video |
| `Enter` | Play in-app |
| `Ctrl + Enter` | Open in external player |
| `B` | Drop bookmark |
| `[` / `]` | Playback speed down or up |
| `Esc` | Stop or exit review |

## Customization

Review shortcuts are customizable in Settings. If you prefer a different hand layout, remap the decision keys there instead of fighting the defaults.
